가라앉는 늪 – 통합 기획서

2026.11.20 / 타디온

게임 전체 구성과, 모든 기획서가 따르는 기준을 정리한 문서입니다.

게임 개요

가라앉는 늪(가제)은 던전 5개 층을 내려가는 액션 로그라이트입니다. 키보드만으로 조작하며, 이동, 공격, 대시, 스킬 2개를 씁니다.

핵심 재미

  1. 예측 안 되는 상황과 환경에 유연하게 대처하기
  2. 선택이 쌓여 빌드가 완성되는 성장 체감
  3. 키보드 조작을 통한 액션감

각 기획서의 의도는 계산할 수 있는 값으로 적고, 대시보드에서 봇 시뮬레이션 결과와 비교합니다. 결과가 의도와 다르면 수치를 조정한 뒤 다시 확인합니다.

플레이 흐름

층 하나가 코어 루프 한 번입니다.

  1. 웨이브 시작. 적이 세 번에 나뉘어 등장
  2. 웨이브의 적을 모두 처치하면 카드 3장 중 1장 선택
  3. 웨이브 1~4를 지나면 웨이브 5는 보스전
  4. 보스를 처치하면 다음 층으로 이동
  5. 5층을 클리어하면 게임 클리어. 이후 무한 모드로 이어짐

체력이 0이 되면 플레이가 끝나고 결과 화면이 나옵니다.

고정 규칙

처음에 정하고 바꾸지 않은 규칙입니다. 다른 기획서는 모두 이 규칙을 따릅니다.

항목내용
장르액션 로그라이트
승패체력은 수치형. 층마다 웨이브 5개, 마지막 웨이브는 보스. 5층을 클리어하면 게임 클리어, 이후 무한 모드로 계속 진행
의도: 클리어 뒤에도 계속 반복해서 플레이할 수 있게
맵미리 만든 맵 10개 중 5개가 무작위 순서로 등장. 현재 프로토타입은 테스트 맵 1개
무작위 요소맵, 적 조합, 환경 조건, 카드 후보, 봇의 반응 시간과 카드 선택. 모두 시드값으로 고정되어 같은 플레이를 그대로 재현할 수 있음
조작키보드 8방향 이동(대각선도 같은 속도), 근접 부채꼴 기본 공격, 대시(이동하는 동안 무적), 스킬 2칸
적몸에 닿아서는 피해가 없고, 공격에 맞아야 피해를 입음. 공격 전에는 항상 예고 동작이 있음. 종류는 근거리형, 원거리형, 돌진형, 방해형(장판형, 디버프형, 적 회복형). 현재 프로토타입은 근거리형, 원거리형 2종
성장웨이브를 클리어할 때마다 카드 3장 중 1장 선택. 경험치 없음. 카드 갈래는 생존, 공격, 평타, 스킬
봇실력 3단계(숙련, 중간, 초보). 적의 예고 동작을 보고 피하기까지 걸리는 반응 시간으로만 구분. 카드 선택은 무작위
테마검은 늪에 잠식된 어두운 던전. 자세한 내용은 콘셉트와 테마 기획서
구조규칙 계산과 화면 표시를 분리. 시뮬레이션은 브라우저에서 실행하며 서버와 LLM은 쓰지 않음

판단 기준

기획 중 선택이 갈릴 때 따르는 기준입니다.

기준이유
비교하려는 것 하나만 다르게, 나머지는 같게경험치가 없는 것도 같은 이유. 잘하는 봇이 보상까지 더 받으면 실력별 비교가 어려워짐
실력 차이는 봇 3단계로 보고, 같은 실력 안에서는 기획 수치와 선택에 따라 결과가 갈리게새 요소를 넣을 때는 봇이 처리할 수 있는지부터 확인. 봇이 처리하지 못하는 상황(예: 여러 발 날아오는 투사체)은 숙련 봇 규칙을 추가하거나 한계로 기록
능력치와 계산식은 단순하게읽을 내용이 많으면 재미가 떨어진다는 것을 직접 경험함. 대시보드에서 수치를 바꿨을 때 결과를 바로 이해할 수 있어야 함
플레이 간 영향 없음 (영구 성장 없음)플레이마다 따로 비교할 수 있어야 시뮬레이션 데이터가 의미 있음
맵과 웨이브는 미리 만든 단위로 구성문제가 있는 맵만 골라 수정하고, 같은 시드로 다시 확인하기 위함
수치는 DT에만 적음수치가 한 곳에 있어야 대시보드와 바로 연결되고, 수정할 곳도 한 곳뿐임
의도는 확인할 수 있는 값으로공식으로 계산한 값이어야 시뮬레이션 결과와 비교할 수 있음
키보드만 사용, 마우스 조준 없음조준이 들어가면 실력을 가르는 요소가 하나 더 생김. 터치패드로 플레이하는 경우도 고려
브라우저 안에서만 동작서버와 LLM을 쓰지 않으므로, 서버나 토큰이 필요한 기능은 넣지 않음

기획서 안내

모든 수치는 DT에서 관리합니다.

기획서주요 내용
콘셉트와 테마게임 이름, 세계관, 캐릭터와 적 외형, 카드 이름, 층 이름, 사운드 방향
시스템 기획전투 규칙(이동, 공격, 대시, 피격), 적 행동, 웨이브 진행, 카드 선택, 스킬, 봇 행동, 화면 흐름
레벨 디자인맵 구성, 웨이브별 적 구성, 층별 보스 배치
보스 기획서보스 패턴, 행동 순서, 공략 방법
DT전체 수치와 설정 이유
대시보드 기획서화면 구성, 기획 의도 검증 방식, 첫 시뮬레이션 결과
