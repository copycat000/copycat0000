대시보드 기획서

Nov 21, 2026 · @타디온

1. 왜 이 툴이 필요한가

유니티 인스펙터처럼 값을 바꿔서 바로 확인하는 창이다. 다른 점은 사람이 한 판 해보는 게 아니라 봇이 수백 판을 돌리고, 그 결과를 기획서에 적은 의도와 비교해준다는 것이다.

기획서에는 "보스는 카드 없이 약 23초면 잡힌다", "약한 봇은 시간 초과가 날 수 있다"처럼 의도를 값으로 적어뒀다. 이게 실제로 그렇게 나오는지는 몇 판 해봐서는 알 수 없다. 대시보드는 실력 3단계 봇으로 판을 대량으로 돌리고, 의도와 어긋난 곳을 숫자로 먼저 보여준다.

통합 기획서에서 대시보드는 마지막 파트다. 게임을 정하는 다른 다섯 파트와 달리, 그 게임이 의도대로 나오는지 검사하는 도구 문서다.

2. 범위

대시보드는 구조를 보여주는 데까지만 만든다. 조정판에는 수치 6개와 판 수만 둔다.

의도: 이걸로 출시할 게임을 만들고 실제로 일하는 게 아니니까 구조만 보여주면 된다.

정하는 것 정하지 않는 것
화면 구성, 조정판에 올릴 수치 항목, 기획서 의도를 검사 규칙으로 바꾸는 방식과 어긋남 비교 방식, 추가로 보여줄 정보 게임 규칙, 수치 값과 맞음 범위(DT), 기록 항목 정의(로그)

본문에는 값을 적지 않고 "DT: 항목명"으로 가리킨다. 예시에 나오는 숫자는 지금 DT에 적힌 값으로 돌린 결과다.

3. 쓰는 흐름

문제 발견 → 수치 조정 → 다시 돌려서 확인, 이 한 바퀴가 화면 한 곳에서 보이는 게 목표다.

  1. 처음 열면 DT 문서 값으로 미리 돌려둔 결과가 나온다.
  2. 기획서 의도 검사 칸에서 "어긋남 N / 검사 M"을 먼저 본다. 누르면 어긋난 줄이 펼쳐진다.
  3. 실력별 결과, 웨이브별 칸 같은 다른 칸을 같이 보고 어느 값을 바꿀지 정한다.
  4. 조정판에서 값을 하나 바꾸고 다시 돌린다.
  5. 조건 목록에 줄이 하나 쌓이고, 직전 결과가 각 그래프에 흐리게 겹쳐 보인다. 어긋남이 줄었는지 바로 비교한다.

값은 한 번에 하나만 바꾼다. 어긋남 하나에 여러 값이 같이 걸려 있어서, 여러 개를 한꺼번에 바꾸면 무엇 때문에 바뀌었는지 알 수 없다. 큰 틀 3번 "비교할 것 하나만 다르고 나머지는 같게"와 같은 기준이다.

예시: 문서 값으로 돌린 첫 결과 (실력별 200판, 시드 1~200)

실력 클리어 사망 시간 초과 평균 받은 피해 평균 도달 층
숙련 179 0 21 4.0 4.58
중간 200 0 0 6.5 5.00
초보 169 31 0 174.4 4.56
  • 시간 초과가 숙련 봇에서만 나온다(21판, 전부 1층). 1층 보스 웨이브 평균은 숙련 26.7초, 중간 25.3초, 초보 24.2초로 DT의 "카드 없이 약 23초"보다 길다.
  • 초보 사망 31판은 전부 보스 웨이브고(1층 5, 2층 18, 3층 7, 5층 1), 전부 내려찍기에 죽었다.
  • 숙련과 중간은 거의 안 갈린다. 일반 웨이브 하나당 받은 피해는 숙련 0.22, 중간 0.32이고, 보스 웨이브는 숙련·중간 모두 0.0, 초보 34.9다. 11/21 결과(보스에서만 갈림)를 보고는 문제로 보지 않았는데(타디온 판단), 11/22 값에서는 보스에서도 거의 안 갈린다.
  • 이 결과는 11/22에 정한 값(치명타 10%, 대시 쿨타임 1초, 슈퍼아머 30, 돌진 예고 2.5초)으로 돌린 것이다.

이 결과가 대시보드를 처음 열었을 때 보이는 "문제 발견" 장면이다. 조정판 수치 중 제한 시간, 보스 체력은 이 결과를 보고 넣었다(5번).

처음 결과에서 어긋난 항목은 포트폴리오 안에서 수치를 고쳐 맞추지 않는다. 문서 값 결과는 의도 검사에서 어긋남 8 / 검사 10으로 나오고(맞음 범위는 임시값), 이 상태 그대로 보여준다.

의도: 조정을 하기 위한 밑재료를 보여주는 게 대시보드의 목적이다.

4. 화면 구성

화면은 칸 9개로 나눠진다. 실제 화면은 대시보드에서 볼 수 있다.

칸 보여주는 것 그림
조정판 바꿀 수치 6개와 판 수, 실행 버튼. 문서 값에서 바꾼 값은 색으로 표시 슬라이더·숫자 칸
돌린 조건 지금 결과가 어떤 값으로 몇 판 돌린 건지. 문서 값에서 바꾼 값만 적음 결과 위 한 줄
기획서 의도 검사 어긋남 개수, 조건별 목록(6번) 숫자 + 목록
실력별 결과 숙련·중간·초보별 클리어·사망·시간 초과 비율, 평균 도달 층·받은 피해·전투 시간 실력마다 이어 붙인 막대 한 줄
어떤 적에게 맞았나 실력별 받은 피해를 근거리형·원거리형·보스로 나눔 실력별 막대
웨이브별 흐름 웨이브마다 평균 걸린 시간, 남은 체력, 죽은 곳. 실력별 선 그래프
실제로 때린 비율 DT 계산값(DT: 카드 없이 초당 피해) 대비 실제 초당 피해, 헛스윙 비율 실력별 막대
카드별 비교 카드마다 고른 판과 안 고른 판의 클리어율 차이, 실력별 카드별 가로 막대
튀는 판 같은 실력 안에서 혼자 튀는 판, 시간 초과 판. 누르면 그 시드로 다시 보기 실력별 상자 그림 + 점

모든 칸에 같이 들어가는 것

  • 봇 실력 설명 한 줄: 숙련·중간·초보는 예고를 보고 피하기까지 반응 시간(DT: 봇 실력별 반응 시간)으로만 나뉘고, 카드는 무작위로 고른다. 화면 위쪽에 둔다.
  • 판 수와 믿을 만한 정도: 차트마다 몇 판 기준인지 적고, 판 수에 비해 차이가 작아 우연일 수 있는 건 흐리게 그린다. 신뢰구간 같은 숫자는 넣지 않는다.
  • 바꾸기 전과 비교: 다시 돌리면 직전 결과를 각 그래프에 흐리게 겹쳐 그린다.

다시 보기는 기획서·프로토타입·대시보드가 같은 사이트에 올라가면 같은 사이트의 프로토타입을 그 시드로 여는 링크가 된다. 시뮬이 믿을 만한지 보여주는 표시(판당 계산 시간, 같은 시드를 두 번 돌렸을 때 결과가 같은지)는 시간이 남으면 넣는다.

5. 조정판 수치

조정판에는 수치 6개와 판 수를 올린다. 기본값은 DT에 적힌 값이고, 여기서는 항목과 넣는 이유만 정한다.

수치 기본값 넣는 이유
치명타 확률 DT: 치명타 확률 처음엔 프로토타입 테스트값과 DT 값이 달라서 대시보드에서 비교하려고 넣음(11/22에 값을 하나로 정리)
대시 쿨타임 DT: 대시 쿨타임 위와 같음
보스 슈퍼아머 DT: 보스 슈퍼아머 위와 같음
한 층 제한 시간 DT: 층당 제한 시간 숙련 봇 시간 초과가 많음(3번 예시)
보스 체력 DT: 보스 체력 보스 처치가 23초보다 오래 걸리고, 초보가 보스에서 죽음
근거리 몬 예고 시간 DT: 근거리형 예고 시간 숙련·중간이 일반 몬에서 안 갈림
판 수 – 한 번 실행할 때 실력마다 돌릴 판 수. 실행 버튼 옆에 둔다

판 수를 100으로 두면 한 번에 300판이고 13초쯤 걸린다. 브라우저에서 30판에 1.3초 걸린 기록을 늘려서 계산한 값이라, 만들고 나서 다시 잰다.

더 넣을 수 있는 후보는 근거리형 공격 범위, 평타 넉백, 묶음 등장 간격이다. 범위를 구조를 보여주는 데까지로 잡아서 지금은 넣지 않는다.

6. 기획서 의도 검사

시뮬을 돌릴 때마다 대시보드가 기획서 의도를 전부 자동으로 검사하고, "어긋남 4 / 검사 12"처럼 숫자를 먼저 보여준다. 의도 표를 사람이 한 줄씩 읽는 방식은 쓰지 않는다.

의도: 정해둔 기획 의도만 체크하는 걸 보여주는 구간이면 번거롭기만 하다. 능동적으로 기획서상의 문제를 점검해주는 형태가 효용이 있다. 예를 들어 a조건에서 어긋남 3줄, b조건에서 10줄이면 b가 더 안 좋다고 바로 보이게.

검사 규칙

시뮬은 서버·AI 없이 브라우저에서만 돌아서 기획서 문장을 직접 읽지 못한다. 그래서 기획서 의도를 검사 규칙으로 옮기는 작업을 처음 한 번 한다.

  • 규칙 하나 = 이름 / 기획서 문장 / 잴 것 / 맞음 범위
  • 맞음 범위는 기획 판단이라 타디온이 정하고 DT에 적는다. 기획서에 "약 23초"처럼 범위 없이 적힌 게 많아서, 규칙을 뽑을 때 후보 범위를 같이 적어 확인받는다.
  • 규칙은 사이트에 올릴 기획서 HTML의 해당 문장에 안 보이게 붙인다. 대시보드는 돌릴 때마다 기획서에서 규칙을 모아 검사하고, 어긋난 줄을 누르면 기획서의 그 문장으로 넘어간다.
  • 규칙 줄 수는 고정이다. 조건을 바꿔도 줄은 그대로고 맞음·어긋남만 바뀐다. 기획서에 의도가 새로 적히면 규칙도 늘린다.

어긋남 보여주기

  • 조건을 바꿔 돌릴 때마다 조건 목록에 한 줄씩 쌓인다. 줄마다 바꾼 값과 어긋남 개수가 보여서 조건끼리 비교된다.
  • 어긋남 개수를 누르면 어긋난 규칙이 펼쳐진다.
  • 어긋난 정도(맞음 범위에서 얼마나 벗어났는지)를 색으로 나눈다. 개수만 보면 가벼운 어긋남 여러 개가 치명적인 하나보다 나빠 보일 수 있어서다.
  • 검사는 맞음·어긋남과 벗어난 정도까지만 알려준다. 어긋남 하나에 여러 값이 같이 걸려 있어서 원인을 하나로 짚지 않는다. 원인은 값을 하나씩 바꿔 다시 돌려서 좁힌다(3번).

검사 규칙 후보

시스템 기획과 DT에서 뽑았다.

기획서 문장 잴 것 지금 기록으로 되나
층당 제한 시간: 약한 봇은 시간 초과가 날 수 있다 (DT) 실력별 시간 초과 수 됨
보스 체력: 카드 없이 약 23초 (DT) 1층 보스 웨이브 평균 걸린 시간 됨
봇 실력: 중간은 근거리형 예고를 못 피한다 (DT) 실력별 근거리형에게 받은 피해 사건 기록에 있음. 판 요약에 옮겨야 함
봇 실력: 초보는 보스 돌진만 피하고 나머지는 거의 맞는다 (DT) 실력별 적 종류별 받은 피해 위와 같음. 보스 내려찍기·돌진이 따로 남는지 확인 필요
묶음 간격: 웨이브 4는 앞 묶음을 못 잡고 겹친다 (DT) 다음 묶음이 간격이 다 지나서 나왔는지 묶음 나온 시각이 사건 기록에 있어 계산 가능
대시 쿨타임: 근거리형 한 마리 공격은 매번 피할 수 있게 (DT) 대시 쿨이라 걸어서 피하거나 맞은 횟수 걸어서 피한 횟수는 있음
평타 쿨감 바닥: 한 판 25장이라 3단계 4장이나 1단계 10장이면 닿을 수 있다 (DT) 바닥에 닿은 판 비율. 평타 각도 최대도 같은 방식 고른 카드 목록으로 계산 가능
파훼를 실력으로 안 나눈 이유: 카드가 쌓일수록 파훼 시도가 늘어나는 게 드러나게 (시스템 6번) 층별 깎으러 붙은 비율 지금은 판 전체 합만 있음. 층별로 남겨야 함
적 3묶음 등장: 빨리 못 잡으면 적이 쌓이는 체감 (시스템 3번) 화면에 동시에 있던 적 수 기록 추가 필요
기본 공격 피해 곱하기: 공격력·평타 카드를 같이 모을수록 서로 키워준다 (시스템 0번) 둘 다 모은 판과 한쪽만 모은 판 비교 고른 카드 목록으로 계산 가능
치명타: 판마다 흔들려도 여러 판 평균에서는 묻힌다 (시스템 0번) 치명타 확률을 바꿨을 때 결과가 흔들리는 정도 됨

봇으로 확인할 수 없어서 뺀 것

  • 웨이브 사이 회복 없음 → 카드 고를 때 전략적 선택: 봇은 카드를 무작위로 고른다.
  • 대시 쿨감 미적용 → 필요할 때만 씀: 봇은 규칙대로만 대시한다.
  • 이동 속도 → 무빙으로 거리 벌기: 봇이 거리 벌기를 하지 않는다.
  • 계산으로 답이 정해진 것(근거리형 10대에 사망 등)도 뺀다.

7. 데이터 흐름

시뮬은 보는 사람 브라우저 안에서만 돈다. 서버가 없고 LLM도 쓰지 않는다.

  • 기본 데이터: DT 문서 값으로 미리 돌려둔 결과다. 11/22부터 프로토타입 값과 DT 값이 같다.
  • 조정판에서 바꾼 값: 브라우저에서 시뮬을 돌릴 때만 쓰인다. DT 파일, 게임, 기본 데이터는 바뀌지 않는다.
  • 결과 저장: 돌린 결과는 브라우저 임시 저장으로 대시보드에 이어지고, 파일로 내려받거나 불러올 수 있다. 저장된 게 없으면 기본 데이터를 보여준다.
  • 검사 규칙: 같은 사이트의 기획서 HTML에서 모은다(6번). 맞음 범위는 DT 값을 따른다.
  • 기록 항목: 판마다 남는 판 요약과 사건 기록을 쓴다. 항목과 저장 형식은 로그 문서를 따른다.

8. DT·로그로 넘길 것

받는 문서 넘길 것
DT 검사 규칙마다 맞음 범위(후보 범위를 적어 타디온 확인 후)
로그 판 요약에 새로 남길 것: 어떤 적(공격)에게 맞았나, 맞을 때 남은 체력(웨이브별), 휘두른 횟수와 맞힌 수, 묶음 나온 시각, 층별 돌진 알아차림·깎으러 붙음, 화면에 동시에 있던 적 수

로그 항목 중 앞의 넷은 게임 사건 기록에 이미 있어서(피격의 공격 주체·남은 체력, 휘두르기의 맞힌 수, 묶음 등장) 판 요약에 옮기기만 하면 된다. 뒤의 둘은 새로 재야 한다.

9. 만들기 전에 확인할 것

  • 파훼 기록: 문서 값 결과에서 파훼 수가 "깎으러 붙음" 수보다 많다(11/22 값 기준 중간 붙음 1,713번·파훼 2,189번). 봇이 돌진을 알아차리기 전에 평타로 슈퍼아머가 깎인 경우가 섞여서다(중간: 붙어서 깨 1,663번 + 알아차리기 전에 깨짐 526번). 그래서 파훼는 이 둘을 나눠 보여준다.
  • 카드 비교 착시: 고른 카드 전체로 비교하면 오래 산 판일수록 카드를 많이 고르니까 아무 카드나 좋아 보인다. 모든 판이 똑같이 고르는 1층 첫 4장만 센다. 그래도 카드마다 50~70판뿐이라(샘플 기준) 차이가 작은 건 흐리게 한다.
  • 화면 멈춤: 돌리는 동안 화면이 멈추지 않게 계산은 뒤에서 따로 돌리고 진행 막대를 보여준다.
  • 조정값 반영: 값을 바꿨을 때 결과가 실제로 바뀌는 게 확인된 건 치명타 확률, 대시 쿨타임, 보스 슈퍼아머 셋뿐이다. 나머지 셋은 넣을 때 하나씩 확인한다.
