프로토타입 진행 메모

마지막 갱신 11/22

어디까지 됐나

첫 테스트 판 1차 완성. index.html을 더블클릭하면 서버 없이 바로 돌아감.

  • 이동(8방향, 대각선 속도 맞춤), 부채꼴 기본 공격, 대시(0.2초 미끄러짐 + 무적)
  • 근거리형, 원거리형 적. 예고 동작(근거리형은 부채꼴이 차오름, 원거리형은 점선 조준선)
  • 웨이브 3묶음(10초가 지나거나 앞 묶음을 다 잡으면 다음 묶음), 웨이브 5개 = 1층
  • 카드 3장(종류 겹치지 않게 뽑고 단계는 60/30/10%), 능력치 9종 + 기본 공격 강화 3종
  • 시작 → 전투 → 카드 → 다음 웨이브 → 층 전환 화면 → 죽으면 결과 화면, 5층 이후 무한 모드
  • 시드 재현: 주소 뒤에 ?seed=숫자. 시드는 콘솔에 찍힘. 시드와 입력이 같으면 같은 판
  • 보스 1(근접 중장형, 보스 기획서 기준): 5번째 웨이브는 보스 혼자 12시 위치에 나옴(1~5층 모두 보스 1). 휘두르기(큰 부채꼴 예고) / 돌진(몸 폭만 한 길 예고 + 슈퍼아머 게이지, 다 깎으면 파훼 그로기, 피해서 벽에 박으면 짧은 그로기). 보스는 안 밀리고 겹치면 플레이어만 밀림. 체력 바는 화면 아래 가운데. 시작 화면에서 5를 누르거나 주소에 ?wave=5면 바로 보스
  • 플레이어 피격 넉백: 공격이 온 반대 방향으로 16px, 0.1초(DT 문서 값). 밀리는 동안 조작 불가(11/20 확정). 보스 돌진은 2배
  • 봇(시스템 기획 6번 기준): 봇 하나에 입구 둘. 다시 보기는 게임 화면 아래 칸에서 실력과 시드를 넣고 "보기"(또는 주소 뒤 #bot=skilled&seed=3, 실력은 skilled/mid/novice). 대량 실행은 bot.html에서 판 수를 넣고 실행, 화면은 항상 꺼짐. 판마다 요약 기록(시드, 끝난 이유, 웨이브별 걸린 시간과 받은 피해, 피하기 횟수, 돌진 알아차림, 깎으러 붙음, 파훼, 벽 충돌, 고른 카드)을 남기고 JSON, CSV로 받을 수 있음. 시간 초과 판은 목록으로 짚고 "이 판 다시 보기" 링크
  • 봇 확인한 것: 시드와 실력이 같으면 대량 실행 결과와 다시 보기 결과가 끝까지 같음(브라우저에서 클리어 판 1개, 시간 초과 판 1개 비교). 판 하나 계산은 Node에서 약 45ms(실력별 20판 평균), 브라우저 30판 1.3초
  • 확인한 것: 브라우저에서 시작부터 카드, 층 전환, 결과까지 오류 없이 넘어감. Node에서 화면 없이 core만 돌려 같은 시드 두 번 결과가 같은 것 확인

    • 위험 범위에서 6px 더 떨어져야 안전으로 봄. 평타 닿는 거리보다 4px 안쪽에서 멈춤(data/bots.js, 임시값)
    • 원거리형 예고 중 위험 범위 = 적에서 조준 방향으로 뻗은 탄 폭만큼의 띠. 쏜 뒤엔 날아가는 탄의 앞쪽 띠. 돌진은 보스 몸 폭만큼의 길
    • 대시로 피하는 동안에는 평타 거리 안 적에게 평타(11/20 직접 결정). 대시 중엔 이동 입력이 바라보는 방향만 바꾸고 미끄러지는 방향은 그대로라, 적 쪽을 보고 침. 걸어서 피할 땐 바라보는 방향이 걷는 방향이라 공격 안 함. 대시가 끝났는데 아직 범위 안이면 같은 방향으로 계속 걸음
    • 돌진 "깎을 수 있나" 계산: 다가가는 시간 = (거리 − 평타 닿는 거리) ÷ 이동 속도. 남은 예고 시간 안에 칠 수 있는 평타 수 × 기대 피해(공격력 × 피해 배율 × 치명타 기대값)가 남은 슈퍼아머 이상이면 붙음. 한 번 정하면 안 바꿈

    • 다시 보기에서 카드, 층 전환 화면을 띄우는 시간은 각 1초(main.js 위 BOT_CARD_SHOW, 그림 쪽 임시값). 다시 보기에선 규칙이 바뀌는 K, L 토글은 막음(대량 실행과 같은 판이어야 해서)
