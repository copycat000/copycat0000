봇 결과를 보고 규칙을 고친 과정

실력별로 시드 1~200을 실행한 결과입니다(클리어, 사망, 시간 초과 횟수).

단계숙련중간초보내용

위험 범위 회피 이동198 / 0 / 2200 / 0 / 0177 / 23 / 0원인 분석: 피한 뒤 원거리형에게 다시 다가가면서 방금 피한 탄의 경로로 다시 들어가 회피를 반복함(60회 기준 숙련 회피 원인: 탄 5,054회, 조준 예고 2,147회, 근거리 1,407회). 다가갈 때 인지한 위험 범위에는 들어가지 않고 돌아가도록 수정(11/20 확정)

이후 숙련과 중간은 결과가 거의 갈리지 않습니다. 봇의 평타 도달 거리(76px)가 근거리형 공격 도달 거리(66px)보다 길고 넉백도 있어서, 근거리형이 예고를 시작하기 전에 밀려나기 때문입니다. 두 단계를 가르는 경계는 반응 시간 0.4초(근거리형 예고 0.6초 − 대시 0.2초)이며, 적이 복잡해지면 수치 조정으로 해결할 문제이며, 수치 조정은 대시보드 단계의 과제입니다. 새 적을 만들 때는 "예고 시간 − 대시 시간이 0.4초 근처인 공격이 실제로 닿는가"를 기준으로 합니다.

테스트값 정리 (11/22)

테스트 중 바꿨던 값을 정리해, 현재 프로토타입 값과 DT 값은 같습니다.

  • 치명타 확률 10% (테스트값 50%, 이전 DT 값 5%)
  • 대시 쿨타임 1초 (플레이해 보고 문제가 없어 유지, DT도 1초로 변경)
  • 보스 슈퍼아머 30 (테스트값 15에서 되돌림)
  • 보스 돌진 예고 1.2초 → 2.5초. 의도: 반응하고 다가가는 시간을 넣으면 1.2초는 너무 짧다

이 값과 스킬 5종이 들어간 현재 결과는 숙련 175 / 0 / 25, 중간 199 / 0 / 1, 초보 167 / 33 / 0입니다.
